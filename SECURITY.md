# Security Policy

## Supported Versions

Since this is a Hackathon project, only the latest version is supported.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As a cybersecurity project (VIF), we take security seriously.

If you discover a security vulnerability within this project, please do **NOT** open a public issue. Instead, please report it privately via:

1.  **GitHub Private Reporting:** Use the "Report a vulnerability" button in the Security tab.

We will acknowledge your report within 48 hours and strive to patch the vulnerability as soon as possible.
